## 💻 Tech Stack & Zero-Friction Architecture

- **Core**: HTML5, Modern ES Modules (`type="module"`), Vanilla Reactive State Store.
- **Styling**: Tailwind CSS (Utility-First responsive layout, dark mode aesthetic, glassmorphism panels).
- **Audio & Voice**: Browser Web Speech API (`SpeechRecognition` & `SpeechSynthesis`).
- **Celebration FX**: Canvas Confetti.
- **Server**: Zero-dependency Node.js HTTP Server (`server.js`).
